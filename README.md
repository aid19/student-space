# StudentSPACE

## Project Description

StudentSPACE is an Android application designed to help students manage study rooms and monitor room availability in real time.

## Features

* Firebase Authentication
* Firestore integration
* Firebase Realtime Database
* Live room status updates
* Room occupancy tracking
* User validation utilities

## Lab 3 Features
